# 订阅 V2 P1 兼容契约

- 订阅 ID 独立于用户 ID。账户可有零至多份订阅，数据库中的可空 `subscriptions.user_id` 表示归属。用户详情、列表及凭据轮换只针对本人记录
- 迁移保留旧 ID、归属、token 哈希及密文、链接路径、节点组和顺序、期限与额度。注册试用随账号写入同一个 D1 batch，沿用试用天数和计划权益
- 公开链接沿用 UA 识别、显式格式及别名、MIME、文件名和 ETag。暂停及不可用归属返回 404，尚未开始返回 403，到期瞬间返回 410。Mihomo 无节点返回 422，节点列表格式沿用空列表与协议不兼容的既有区别。已有停用的计划撤销记录继续停用
- 按简报更新授权。无计划和未分配订阅按已配置分组下发。之后撤销计划归属或停用计划不停止已发订阅。订阅本身的停用、有效期和用户状态仍实时生效
- P1 沿用订阅已有的节点组选择，含组内指定节点。订阅级节点选择器与独立权益模板属于 P2。额度用于配置和展示，拉取统计独立于数据面计量
